Assignment 1: OpenGL 2D Primitives
This project contains the source code for Assignment 1, which covers drawing basic and complex 2D shapes using modern OpenGL.

Dependencies
Before compiling, ensure you have the following libraries installed:

GLFW: For creating windows and handling input.

GLAD: For loading OpenGL function pointers.

A C++ compiler that supports C++11 (e.g., g++, Clang).

OpenGL libraries.

Compilation
The project includes a Makefile to simplify the compilation process.

Open a terminal in the root directory of the project.

Run the make command:

make

This will compile all source files and create three executables: task1, task2_part1, and task2_part2.

How to Run
After successful compilation, you can run each program from the terminal:

Task 1: Red Triangle and Blue Square
To run: ./task1

Controls:

Press the 1 key to display the red triangle.

Press the 2 key to display the blue square.

Task 2, Part 1: Specified Scene
To run: ./task2_part1

Description: This program displays the scene with a circle, ellipse, triangle, and concentric squares as specified in the assignment PDF.

Task 2, Part 2: Creative Scene
To run: ./task2_part2

Description: This program displays a creative scene of a flower with petals, a center, and grass, built using the concepts from the assignment.
